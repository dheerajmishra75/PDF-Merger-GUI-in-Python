# PDF Merger GUI in Python

A simple desktop application for selecting multiple PDF files and merging them into one PDF.

## Requirements

- Python 3.9 or newer
- Tkinter, usually included with standard Python installations

Install the Python dependency:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Use **Add PDFs** to select files, optionally remove or clear selections, and choose **Merge** to save the combined PDF.
